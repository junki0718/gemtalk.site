# gemtalk PLAYGROUND (온라인 미니게임 플랫폼)

친구들과 내기할 때, 심심할 때 혼자 즐기거나 여러 명이 모였을 때 즉시 즐길 수 있는 **무설치·무가입 100% 프론트엔드 온라인 미니게임 웹 플랫폼**입니다.

---

## 🌟 주요 특징

- **복잡한 가입/로그인 없음**: 링크 접속 즉시 모든 게임 무료 플레이 가능
- **15가지 풍성한 캐주얼 미니게임**:
  1. **랜덤 / 내기 게임** (사다리 타기, 룰렛 돌리기, 제비뽑기, YES or NO)
  2. **반응속도 / 기록 경쟁** (반응속도 테스트, 타자 속도 테스트, 색깔 맞추기, 숫자 순서 맞추기)
  3. **두뇌 / 캐주얼 게임** (2048, 가위바위보, 카드 짝 맞추기, 지뢰찾기)
  4. **친구들과 함께하는 게임** (초성 퀴즈, 업다운 게임, 밸런스 게임)
- **자체 내장 Web Audio 효과음 & 축하 콘페티 파티클 시스템**: 외부 음원/에셋 다운로드 없이 브라우저 자체 합성음으로 실감 나는 사운드와 시각 효과 제공
- **LocalStorage 영구 기록 보관**: 게임별 최고 점수, 최고 반응속도, 최소 시도 횟수, 연승 기록이 브라우저에 자동 저장
- **PC & 모바일 완벽 반응형 UI**: 터치 스와이프, 키보드 방향키, 마우스 클릭/우클릭 모두 지원

---

## 🚀 실행 방법

### 방법 1. 웹 브라우저에서 바로 열기
`gemtalk-playground` 폴더 내의 `index.html` 파일을 크롬, 엣지, 사파리 등의 브라우저로 더블 클릭하여 즉시 실행할 수 있습니다.

### 방법 2. 로컬 웹 서버 실행
```bash
cd gemtalk-playground
python -m http.server 8080
```
웹 브라우저에서 `http://localhost:8080` 으로 접속하면 바로 플레이할 수 있습니다.

## 🎮 구현된 15가지 게임 상세

| 카테고리 | 게임 이름 | 핵심 기능 및 규칙 |
| :--- | :--- | :--- |
| **랜덤 / 내기** | **사다리 타기** | 2~8명 참가자/결과 직접 입력, 캔버스 사다리 자동 생성, 실시간 경로 추적 애니메이션, 전체 결과 한눈에 보기 |
| **랜덤 / 내기** | **룰렛 돌리기** | 항목 추가/삭제, 점심/벌칙/추첨 프리셋, 물리 감속 관성 회전 애니메이션, 당첨자 안내 |
| **랜덤 / 내기** | **제비뽑기** | 참가자 및 당첨/꽝 설정, 카드 뒤집기 애니메이션, 개별 열기 및 모두 열기 지원 |
| **랜덤 / 내기** | **YES or NO** | 질문 입력, 신비의 운명 오브 회전 애니메이션, 명쾌한 결정 및 유쾌한 조언 코멘트, 히스토리 |
| **반응 / 기록** | **반응속도 테스트** | 화면 색상 변경 순간 밀리초(ms) 측정, 조기 클릭 방지, 5회 평균 계산 및 게이머 랭크 분류 |
| **반응 / 기록** | **타자 속도 테스트** | 명언/속담/긴 문장 실시간 타이핑, 실시간 분당 타수(CPM) 및 정확도(%) 측정, 최고 기록 저장 |
| **반응 / 기록** | **색깔 맞추기** | 스트룹(Stroop) 인지 효과 게임, 30초 타이머, 콤보 시스템 및 최고 점수 저장 |
| **반응 / 기록** | **숫자 순서 맞추기** | 5x5 그리드 1~25 숫자 슐테(Schulte) 순발력 스피드런, 100분의 1초 스톱워치 측정 |
| **두뇌 / 캐주얼** | **2048** | 방향키 및 모바일 터치 스와이프 지원, 타일 결합 점수, 2048 승리 달성 판정 |
| **두뇌 / 캐주얼** | **가위바위보** | 컴퓨터와의 심리 대결, 셔플 연출, 연승 카운터, 통산 전적(승/무/패) 및 최고 연승 기록 |
| **두뇌 / 캐주얼** | **카드 짝 맞추기** | 16장(8쌍) 3D 카드 뒤집기, 시도 횟수 및 소요 시간 측정, 최소 시도 신기록 저장 |
| **두뇌 / 캐주얼** | **지뢰찾기** | 초급(8x8)/중급(10x10)/고급(12x12), 첫 클릭 안전 보장, 깃발 모드 토글, 빈칸 자동 확장 |
| **친구들과 함께** | **초성 퀴즈** | 영화, 음식, 사자성어 등 풍부한 문제 뱅크, 20초 카운트다운, 힌트 보기 및 스킵 기능 |
| **친구들과 함께** | **업다운 게임** | 1~100 숫자 추측, 탐색 범위(Min~Max) 동적 압축 시각화, 시도 기록 칩 제공 |
| **친구들과 함께** | **밸런스 게임** | 딜레마 질문 투표, 대중의 실시간 통계 퍼센트 바 애니메이션, 나만의 질문 추가 기능 |

## 📁 파일 구조

```
gemtalk-playground/
├── index.html            # 메인 HTML 및 단일 페이지 라우터 (SPA)
├── css/
│   ├── style.css         # 플랫폼 메인 레이아웃, 모던 캐주얼 디자인 시스템, 테마
│   └── games.css         # 15개 게임별 전용 UI, 보드, 카드, 캔버스 스타일
└── js/
    ├── app.js            # 중앙 애플리케이션 엔진 (라우터, 사운드 FX, 콘페티, 검색)
    └── games/
        ├── ladder.js     # 사다리 타기 로직
        ├── roulette.js   # 룰렛 돌리기 로직
        ├── draw.js       # 제비뽑기 로직
        ├── yesno.js      # YES or NO 로직
        ├── reaction.js   # 반응속도 테스트 로직
        ├── typing.js     # 타자 속도 테스트 로직
        ├── color.js      # 색깔 맞추기 로직
        ├── schulte.js    # 숫자 순서 맞추기 로직
        ├── g2048.js      # 2048 로직
        ├── rps.js        # 가위바위보 로직
        ├── memory.js     # 카드 짝 맞추기 로직
        ├── minesweeper.js# 지뢰찾기 로직
        ├── choseong.js   # 초성 퀴즈 로직
        ├── updown.js     # 업다운 게임 로직
        └── balance.js    # 밸런스 게임 로직
```
